# Prototyp der Bedienoberfläche

`index.html` ist eine einzelne, in sich geschlossene Datei. Kein Build, keine
Abhängigkeiten außer den Schriften von Google Fonts.

## Ansehen

| Weg | Adresse |
|---|---|
| Lokal | Datei doppelklicken, öffnet sich im Browser |
| Über die laufende App | `/prototyp/` (alles unter `public/` wird direkt ausgeliefert) |

## Wozu

Der Prototyp zeigt den gewünschten Funktionsumfang und markiert bei jedem
Baustein den ehrlichen Bauzustand:

- **Gebaut** läuft so im Code
- **Teilweise** Gerüst steht, Inhalt fehlt
- **Entwurf** nur gestaltet, noch nicht gebaut
- **Gesperrt** die Plattform lässt es nicht zu

Er ist die Diskussionsgrundlage für den Ausbau, keine laufende Anwendung.
Die Zahlen darin sind Beispieldaten und als solche gekennzeichnet.
